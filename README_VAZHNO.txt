Что изменено:

1. Убрана кнопка и маршрут сброса демо-данных /dev/reset.
2. Аватары больше не загружаются в static/uploads, а выбираются из готового списка.
3. Готовые аватары лежат в static/img/avatars/.
4. База данных хранится в instance/profischool.db рядом с проектом.

ВАЖНО:
Чтобы данные не пропадали при переносе на другой ПК, переносите всю папку profischool_app целиком, особенно папку instance с файлом profischool.db.
Если перенести только app.py без instance/profischool.db, база создастся заново и снова будут только демо-данные.

Запуск:
1. Откройте терминал в папке profischool_app.
2. Установите зависимости: pip install -r requirements.txt
3. Запустите: python app.py
