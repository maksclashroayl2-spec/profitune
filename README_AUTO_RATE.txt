Добавлена автоматическая ставка репетитора.

Режимы ставки в разделе «Репетиторы» -> «Мои репетиторы»:
- Вручную: используется ставка из поля «Ставка ₽/час».
- Автоматически: ставка считается по часам конкретной недели:
  - меньше 16 часов: 400 ₽/час;
  - 16 часов и больше: 500 ₽/час.

База данных не сбрасывается. При запуске migrate_schema() добавит колонку hidden_tutor_pool.rate_mode, если её нет.
